# FocusFlow: Responsive Landing Page

**Arithmatrix Virtual Internship Program (AVIP) 2026 | B.Y.T.E | Web Development | Task 1**

FocusFlow is a landing page for a **concept** study-planner app for students. The product is a demo created for this task; it is not a real app.


**Live demo:**  https://zeinabdawi5-cloud.github.io/WD_1_ResponsiveLandingPage_BYTE/
**GitHub repository:** https://github.com/zeinabdawi5-cloud/WD_1_ResponsiveLandingPage_BYTE

## Task requirements and how they are met

| Requirement | Where it is in this project |
|---|---|
| Responsive on desktop, tablet and mobile | `style.css` breakpoints at 600px, 768px and 992px |
| Hero section | `index.html`, `<section id="hero">` |
| Product features | `index.html`, `<section id="features">` with 6 feature cards |
| Clear call-to-action | "Try the demo planner" in the hero and "Get early access" at the bottom |
| Interactive UI element | Working demo planner (tick tasks and the progress bar updates), mobile hamburger menu, card hover effect |
| Meta tags and semantic HTML | `<title>`, `<meta name="description">`, viewport tag, `lang="en"`, and `header`, `nav`, `main`, `section`, `article`, `footer` |

## Responsive layout

| Screen | Width | Features grid | Navigation |
|---|---|---|---|
| Mobile | up to 599px | 1 column | Hamburger menu |
| Tablet | 600px to 991px | 2 columns | Hamburger menu below 768px, full bar from 768px |
| Desktop | 992px and up | 3 columns | Full bar, two-column hero |

## Technologies

HTML5, CSS3 (Grid, Flexbox, media queries) and vanilla JavaScript. No frameworks. Fonts: Bricolage Grotesque and Source Sans 3 from Google Fonts, with system-font fallbacks.

## Run locally

1. Download or clone this repository.
2. Open `index.html` in any browser.
